---
title: "Create a Ban"
api: "POST https://api.lumonol.co.uk/bans/create"
description: "Create a new remote ban for a player. This will immediately mark them as banned in the database and push the update to your live servers."
---

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<ParamField body="roblox_user_id" type="integer" required>
  The Roblox User ID of the player to ban.
</ParamField>

<ParamField body="reason" type="string" required>
  The reason for the ban.
</ParamField>

<ParamField body="moderator_id" type="string" required>
  The profile ID of the staff member who issued the ban.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lumonol.co.uk/bans/create?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "roblox_user_id": 12345678,
    "reason": "Exploiting in server",
    "moderator_id": "uuid-of-moderator"
  }'
```
</RequestExample>
