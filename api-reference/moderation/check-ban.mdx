  The Roblox User ID to check.
</ParamField>

</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.lumonol.co.uk/bans/12345678?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
