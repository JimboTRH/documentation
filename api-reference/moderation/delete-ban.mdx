---
title: "Unban a Player"
api: "DELETE https://api.lumonol.co.uk/bans/delete/{banId}"
description: "Revoke an existing ban, allowing the player to join the game again."
---

<Warning>
  This completely removes the ban record. If you wish to keep a history of the ban, consider using the Edit Ban endpoint to set `is_active` to false instead.
</Warning>

<ParamField path="banId" type="string" required>
  The unique ID of the ban record to delete.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.lumonol.co.uk/bans/delete/uuid-of-ban?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
