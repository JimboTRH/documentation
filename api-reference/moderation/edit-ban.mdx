---
title: "Edit a Ban"
api: "PATCH https://api.lumonol.co.uk/bans/update/{banId}"
description: "Modify an existing remote ban's details."
---

<ParamField path="banId" type="string" required>
  The unique ID of the ban record to edit.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<ParamField body="reason" type="string">
  The new reason for the ban.
</ParamField>

<ParamField body="moderator_id" type="string">
  The new moderator profile ID.
</ParamField>

<ParamField body="is_active" type="boolean">
  Set to false to deactivate the ban without deleting it completely.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lumonol.co.uk/bans/update/uuid-of-ban?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "Updated exploiting evidence"
  }'
```
</RequestExample>
