---
title: "Register a Server"
api: "POST https://api.lumonol.co.uk/sessions/{sessionId}/servers/create"
description: "Register a newly created Roblox server instance into the database so the web dashboard knows it exists."
---

<ParamField path="sessionId" type="string" required>
  The unique ID of the session.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<ParamField body="label" type="string">
  The name of the server (e.g. "Server 1 - Training Room").
</ParamField>

<ParamField body="server_code" type="string">
  The private server join code.
</ParamField>

<ParamField body="created_by_roblox_id" type="integer">
  The Roblox User ID of the host.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lumonol.co.uk/sessions/uuid-of-session/servers/create?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Server 1 - Training Room",
    "server_code": "PRIVATE_SERVER_JOIN_CODE",
    "created_by_roblox_id": 12345678
  }'
```
</RequestExample>
