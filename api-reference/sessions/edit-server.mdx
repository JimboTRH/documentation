---
title: "Edit a Server"
api: "PATCH https://api.lumonol.co.uk/sessions/servers/update/{serverId}"
description: "Modify an existing session server's details."
---

<ParamField path="serverId" type="string" required>
  The unique ID of the server record to edit.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<ParamField body="label" type="string">
  The new name of the server (e.g. "Server 2 - Overflow").
</ParamField>

<ParamField body="server_code" type="string">
  The new private server join code.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH "https://api.lumonol.co.uk/sessions/servers/update/uuid-of-server?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Server 2 - Overflow"
  }'
```
</RequestExample>
