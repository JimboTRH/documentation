---
title: "Delete a Server"
api: "DELETE https://api.lumonol.co.uk/sessions/servers/{serverId}"
description: "Delete a session server from the database. Use this when the server shuts down or the session concludes."
---

<ParamField path="serverId" type="string" required>
  The unique ID of the server record.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.lumonol.co.uk/sessions/servers/uuid-of-server?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
