---
title: "Assign a Role"
api: "POST https://api.lumonol.co.uk/sessions/{sessionId}/assign-role"
description: "Assign a player to a session role. If the player does not have a Kith profile yet, the system handles it automatically."
---

<ParamField path="sessionId" type="string" required>
  The unique ID of the session.
</ParamField>

<ParamField query="workspace_id" type="string" required>
  Your unique Workspace ID.
</ParamField>

<ParamField body="roblox_user_id" type="integer" required>
  The Roblox User ID to assign to the role.
</ParamField>

<ParamField body="role_id" type="string" required>
  The unique ID of the session role being assigned.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST "https://api.lumonol.co.uk/sessions/uuid-of-session/assign-role?workspace_id=YOUR_WORKSPACE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "roblox_user_id": 12345678,
    "role_id": "uuid-of-role"
  }'
```
</RequestExample>
